# Personal Expense Tracker 💰

A simple React-based web application that helps users track daily expenses, categorize spending, and view total spending in real time. Data is stored locally using browser Local Storage.

---

## 🚀 Features

* Add new expenses
* Delete expenses
* Filter expenses by category
* View total spending
* Persistent data using Local Storage
* Simple and clean dashboard UI

---

## 📂 Categories

* Food
* Transport
* Entertainment
* Other

---

## 🛠️ Tech Stack

* React (Vite)
* JavaScript (ES6+)
* HTML & CSS
* Local Storage (for persistence)
* Git & GitHub

---

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/your-username/expense-tracker.git
```

Navigate into the project:

```bash
cd expense-tracker
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

## 💡 How It Works

1. User adds an expense (title, amount, category, date)
2. Expense is stored in React state
3. Data is saved to Local Storage
4. UI updates automatically
5. Users can filter and delete expenses anytime
